# 3D-Printing-Models
A Repository to host my 3D Models that I've used with my 3D printer.

Tools used:

- Bambu Lab P1S: Main Printer, mostly used with PLA and PETG

- OrcaSlicer for processing Models: [Link](https://www.orcaslicer.com/)

- Freecad for designing my models: [Link](https://www.freecad.org/)
